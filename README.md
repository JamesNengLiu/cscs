# LAN STRIKE v0.5 — 原版人物与匪徒定制面部开发版

版本日期：2026-10-28。用于可信局域网和本地开发验证。武器与经济、人物、流畅度优化及游戏菜单已统一纳入 `main`。按用户要求，后续直接在 `main` 修改、测试和提交，不再单独创建功能分支；既有分支仅保留历史，不自动删除。开发约定见 [AGENTS.md](AGENTS.md)。部署已统一为最新v0.5单实例、3001端口；旧v0.3源码目录保留，但旧服务已关闭。

> **代码仓库不包含原版地图/武器/人物、肖像及派生资源。** 克隆后不能直接玩；先按 [ASSETS.md](ASSETS.md) 准备有权使用的本地素材。下文“本机已有资源”不代表仓库附带素材。

## 这次接入了什么

### 单人开局与对手加入

单人或同一阵营即可直接开始回合，在购买区和购买时间内购买，并正常移动、射击、安包。超时、爆炸或全灭仍按规则结束并自动进入下一回合。首个对立阵营玩家加入时重开当前回合，重置出生、炸弹和计时，进入正常准备阶段；同队加入不重置回合且可立即行动。已经双方在场的对局仍让中途加入者等待下一回合。对手离开后剩余玩家继续当前回合，房间无人时才回到等待状态。

### 回合结束后继续操作

回合结束后的6秒倒计时内，存活玩家可以继续移动、跳跃、开火、换弹、切枪和开镜；胜负、比分及已结算的回合奖励保持锁定，安拆包停止。倒计时结束后自动进入下一回合，按既有流程重生、补满弹药并准备开局。

专项验证：`npm run test:round-end` 使用临时副本中的合成地图检查规则；`npm run test:round-end:browser` 在临时回环服务上通过真实客户端、WebSocket与Game验证输入、预测、开火及自动换回合。后者使用合成地图和测试展示模型，不代表原图/模型或实体多机验收；测试进程结束后清理服务与副本。

### 免费弹药与开镜灵敏度

- 购买主武器或手枪时附赠满弹匣和满额备用弹药，只扣枪械价格。每个新回合开始，携带枪械的弹匣与备弹免费补满；回合内射击、换弹仍正常消耗弹药。
- 商店移除弹药分类与商品，服务端也不再接受旧版弹药购买请求。上述补给方式是本项目自定义规则。
- 游戏菜单新增“狙击枪开镜灵敏度”：0.10×–5.00×，乘在普通鼠标灵敏度上，默认1.00×保持之前手感；对狙击枪各开镜档位生效，自动保存在本机。“恢复默认灵敏度”同时重置两项。

### 不引入 Wasm 的流畅度优化

新增[游戏菜单与鼠标灵敏度](docs/game-menu-2026-10-28.md)：大厅点击“游戏菜单”，对局按Esc打开。灵敏度0.10×–5.00×、默认1.00×兼容旧手感，滑条/数字即时生效、本机自动保存、可恢复默认。菜单清空移动/开火但不暂停局域网对局；点击“继续游戏”恢复鼠标捕获。专项验证：`npm run test:menu`。合并菜单后提交前318项Node测试通过，零失败、零跳过。

- 人物、第三人称枪与第一人称武器/手臂改为 WebGL 2 GPU 刚性蒙皮，仅更新骨骼矩阵，保留原身体、UV、源动画和权威规则。
- HUD/战绩表按变化更新，小地图最高30次/秒；远端位置与转向按帧率无关方式平滑；武器缓存有界并回收资源。
- 大厅与Esc暂停页新增“自动 / 优先流畅 / 优先清晰”。自动档只在可靠异步GPU计时确认持续过载时降分辨率，无计时支持时保持默认、可手动切换。HUD与模拟频率不降低。
- 本地313项自动化测试、两种渲染器各132组CPU/GPU画面对照、十连接单渲染器与原有浏览器回归通过。**不是十台实体设备帧率验收，不承诺稳定60/120FPS。** 详细实测范围、工作负载和复验见[流畅度优化验收](docs/smooth-rendering-2026-10-28.md)。

### 原版人物与定制面部

- 8个CS人物原始MDLv10的身体几何、皮肤、骨骼与每人111段源动画，包含9向混合；不是用原型盒子替代。相对于本地源文件逐顶点/UV/贴图/动画校验，不代表Valve零售版认证。
- 4个匪徒新增特朗普定制三维头部，保留各自原版身体和服装；警察保持原版。T默认`terror_trump`，大厅可选择其他外观或原版对照。外观不改变队伍、资金、伤害和碰撞规则。
- 默认不登录或加入游戏即可预览：`/characters.html?model=terror_trump&compare=1`。支持正/侧面、全身、原版对照、源动画、24把第三人称枪械。
- 特朗普脸采用官方正面肖像投射到新建低模头部，有鼻部/头颅体积和侧背面；**不是本人三维扫描，也不声称面部或侧脸1:1**。明确标为虚构娱乐外观，不代表本人或官方参与。
- 8个原版模型未做独立零售版哈希认证；动画状态选择、上下身步态叠加、环境chrome/光照等仍不是原版引擎级复现。详见 [人物接入](docs/characters-integration.md)、[源资产审计](docs/player-asset-fidelity.md) 和 [渲染限制](docs/player-renderer.md)。

继承上一版的武器、购买和经济功能：

- 24把枪、免费刀、HE/闪光/烟雾、护甲/头盔、拆弹器、夜视仪和CT盾牌。枪械与装备需要真实扣款购买，弹匣与备弹随买枪赠送并在新回合免费补满。
- 开局资金按用户要求为 **$10,000**，上限 **$16,000**；只在首次加入初始化，不是每回合重置。阵营默认手枪与刀免费，其余按规则购买。
- 源BSP己方购买区、90秒购买窗；服务端核验资格、余额、阵营、库存与携带上限，不接受客户端自报金额、伤害或位置。
- 按ReGameDLL参考核对购买价格、口径共享、护甲、击杀/胜负奖励、完整连败状态、T超时存活无补助等规则，不套用CS:GO经济。当前准备6秒、回合150秒（2分30秒）、炸弹45秒；回合时长按用户要求从参考默认300秒缩短。已安放炸弹仍可延长回合至拆除或爆炸；用户可配置的服务器参数不等于所有CS服务器都一样。
- 持有武器切换、丢弃/拾取、霰弹枪逐发装填、三连发、消音器、瞄准镜和盾牌防护。
- 本地转换30份真实MDLv10第一人称模型、原始皮肤和骨骼轨道。缺失时明确显示紫红线框占位，不以占位通过原版模型验收。
- 保留原图碰撞及固定60Hz、ACK确认/未确认输入重放的下坡同步修复，不通过改图掩盖位置回拉。

**不能称完整1:1：** 移动引擎、逐枪散布与后坐力、骨骼命中盒、子弹穿透、动画事件/声音、世界模型、烟雾和夜视显示仍有近似或缺失。详见 [接入验收](docs/equipment-integration.md)、[规则来源](docs/cs16-sources.md)、[模型忠实度](docs/weapon-model-fidelity.md) 和 [投掷物限制](docs/grenades-fidelity.md)。

## 运行

开发机已备资源。若从代码检出，须先完成ASSETS中的资源准备：

```sh
npm ci
HOST=0.0.0.0 PORT=3001 npm start
```

- 部署统一使用3001单实例。启动前检查现有监听，不重复开多个版本；服务是否正在运行以实时health检查为准。
- 主机用 `http://localhost:3001`；其他电脑用主机当前局域网IP与3001端口，不能用另一台电脑自己的localhost；IP变化后重新查询。
- 仅限可信局域网；不自动开放防火墙，不配置公网转发。仅本机测试用 `HOST=127.0.0.1`。
- 桌面Chrome/Edge、WebGL、键盘鼠标。单人即可开局、购买和自由行动；无机器人，另可进入静态地图预览。
- Windows PowerShell先设置 `$env:HOST="0.0.0.0"; $env:PORT=3001`，再 `npm start`。
- 服务重启会断开连接；更新后所有窗口刷新重连。Ctrl+C停止对应进程，不停止其他版本。

## 操作

WASD移动；左键射击/投掷，右键副功能（刀刺/开镜/切连发/消音器/举盾）。

B购买；1主武器、2手枪、3刀、4切换投掷物、5 C4；Q上一武器、滚轮切换、G丢弃、R换弹、N夜视。

空格跳跃、C蹲下、Shift慢走、E静止安拆包/交互、Tab战绩、Esc释放鼠标。打开购买菜单会清空按住的移动/射击输入；点击“继续游戏”重新捕获鼠标。

## 原始地图与重建

活动地图不是估算灰盒：相对于已下载的社区镜像BSP，保留源多边形、UV、原始站立/蹲伏/点射线碰撞hull、出生点和爆破/购买触发模型。

统一坐标转换为 `(X,Y,Z) -> (X,Z,-Y)/40`；40是内部单位换算约定，不是现实米制实测。44张地图贴图、4002个可见面、9932个三角形；首个静态light style与六面天空，不是原版gamma逐像素复现。

```sh
npm run import:map
# 或 python3 tools/import-map.py --source /path/to/local/map-assets
# 天空来源与使用授权确认后，才手动运行：
python3 tools/fetch-sky.py
```

默认原始目录为同级 `lan-strike-original-map-2026-10-27/`，包括 `de_dust2-csboost.bsp` 与补齐引用贴图的WAD。转换生成 `public/map-data.js`、`public/assets/dust2/` 和地图导入报告。

源地图SHA-256：`15945389528d113562ede0a2c80647ebfa799079ed1c05a25379bcf84e4e9286`。镜像一致不是Valve官方版本认证。

## 跨设备卡顿诊断

在出现问题的电脑上进入对局，按Esc → “联机诊断” → “重置诊断采样”，继续游戏30–60秒，卡顿后立即再次按Esc并“导出诊断JSON”。报告仅在本地下载，不自动上传；保留真实RTT峰值、状态到达间隔、前台帧间隔、长任务、输入积压、位置纠正和服务器调度信息。详见[诊断说明与口径](docs/network-diagnostics-2026-10-28.md)。这次只增加采样，不更换WebTransport、不改变同步频率或玩法。专项复验：`npm run test:diagnostics`。

npm run test:characters

- 规则测试自动发现 `tests/*.test.mjs`；武器/经济集成覆盖24把枪的购买、切换、开火，以及余额、奖励、护甲、投掷、携带与死亡规则。
- `test:map` 对照源坐标/UV/碰撞树/实体，再用真实移动函数重放五条出生到包点路线；首次运行前先导入，不能复制旧导入报告冒充本次校验。
- `test:browser` 用临时127.0.0.1随机端口和两个隔离Chrome会话，真实WebSocket购买/扣款、开局、移动、跳跃、开火、换弹、断线；finally关闭临时服务并核查端口。
- `test:shop` 包含独立菜单测试及**拦截传输的客户端夹具**，用于UI/闪光/烟雾，不作为真实服务端联网证据。
- 下坡真实浏览器夹具只通过父进程IPC设置点位，不为生产服务器增加传送接口。
- `test:tuning` 仍是旧原型参数的确定性比较，不是CS原版枪感认证。

本地报告与截图位于忽略的 `artifacts/`。实体双机Wi-Fi、10人负载、目标硬件FPS、原版逐帧对照尚未验收。测试通过不等于完整原版还原。
