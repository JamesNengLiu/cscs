# v0.5 人物与匪徒定制面部接入

版本日期：2026-10-28（Asia/Shanghai）。开发分支：`feat/cs16-player-trump`。继承武器/经济提交 `48f401864ab09532be0dde0c111d4dc4b9589d40`；提交状态以Git远端分支为准。按后续用户要求，部署已统一为最新v0.5单实例、3001端口，旧v0.3与3003服务已关闭；旧源码目录保留。

## 目标与结论

将原型人物替换为CS源人物网格/皮肤/骨骼，再提供匪徒的特朗普定制头部；玩家能够在大厅选择外观、在对方客户端看到真实模型，并独立检查正侧面/动作。

- 已接入8个原始人物文件：T的`terror/leet/arctic/guerilla`，CT的`urban/gsg9/sas/gign`。
- 每个人物111段源动画，保留全部1向/9向混合轨道；不是只导出静态T-pose。骨骼、调色板、UV、纹理像素、命中盒数据和动画样本对照原始MDL校验。
- 4个T人物分别生成`*_trump`外观。除头部三角面移除/替换外，身体顶点、法线、UV、原贴图和骨骼/动画/源命中盒数据不改变。
- 默认T为`terror_trump`，CT为`urban`；可选择其他同阵营外观，原版T保留作对照。
- 第三人称的24把原始`p_*`枪械按骨骼名合并到持枪姿势，不用小方块充当原版枪。

**忠实度边界：** “保留源人物模型”相对于本地取得的MDL文件成立；这些人物未完成第二来源/官方零售版认证。自定义特朗普头部是单张官方正面肖像投影到新建低模头部，不是面部扫描，不声称精准侧脸或整套原版渲染/动作状态机1:1。

## 范围与非目标

本期必须项：8个原版模型、4个定制头部、源骨骼动画、同阵营外观选择与权威复制、正侧面预览、源数据对照、真实浏览器验证、素材与代码分离。

本期不做：原版引擎移植、官方零售版认证、真人三维扫描、表情/口型、上下身步态完整叠加、GoldSrc chrome/原版gamma逐像素复现、骨骼命中盒玩法替换、10人性能承诺。头像外观不改变碰撞、武器和经济。

## 来源与生成

1. 8个人物来源为 `https://www.vertigogaming.org/downloads/cstrike/models/player/{id}/{id}.mdl`。原始散列/日期/权利未知项保存在忽略目录的`sources.json`和manifest。第二个人物镜像尝试全部404，不能写成双源一致。详见 [源资产审计](player-asset-fidelity.md)。
2. 特朗普肖像来源为 [White House官方2025 PNG](https://www.whitehouse.gov/wp-content/uploads/2025/06/President-Donald-Trump-Official-Presidential-Portrait.png)。源文件固定散列，变更后拒绝静默继续。原图3000×1688，生成器记录实际裁剪区域。
3. `tools/build-trump-face.py`新建低模头颅、鼻部、下颌、耳部和短颈，适配到4种身体的原始头骨。肖像与近似侧背面着色写入同一连续环绕atlas，并按纬度校正正面投影宽度；后脑UV通过重复tile展开，避免正背两张材质硬拼的接缝。只有原头骨对应的全头部三角面被替换；原始文件与8个原版派生模型保留。新建头型不是特朗普真实扫描几何。
4. 自定义头部方向由原始中性持枪姿势与bind pose之间的骨骼变换反算，不能假设bind的`+X`就是面朝方向，否则会转侧/低头。新增头部使用原始头骨，不改变物理命中区域。
5. 自定义模型明确使用`source:'custom-trump-face'`、`baseSourceSHA256`和独立派生散列；不冒充原版。版权与肖像/商标/背书范围分别处理。公开可下载不是CS素材再分发授权。

原始、派生、肖像、来源清单及素材截图均保持在忽略的`public/assets/`或`artifacts/`，不纳入公开代码。

## 运行与验收入口

本机有资源时：

```sh
npm ci
HOST=0.0.0.0 PORT=3001 npm start
```

- 游戏：`http://<主机当前局域网IP>:3001/`；桌面键鼠，双方各1人才能开始，无机器人。IP变更后须重新查询，不沿用旧地址。
- 原版/定制对照：`/characters.html?model=terror_trump&compare=1`。
- 单独看脸：`/characters.html?model=terror_trump`。
- 预览页不连接WebSocket、不占游戏名额；支持旋转、正/侧面、全身、源动作/指定序列、暂停/重播和24把枪械。
- 可信局域网使用，不配置公网转发。另一台电脑不能使用它自己的localhost。
- 重建顺序与Pillow安装见 [ASSETS.md](../ASSETS.md)。先导原版，最后生成定制头部；现有成功加载的页面需要刷新，才能丢弃旧manifest/模型缓存。

## 联机规则与异常

| 场景 | 行为 |
| --- | --- |
| 加入时指定合法同阵营外观 | 服务端保存，所有快照复制`character`，复活保留 |
| T提交CT外观、未知ID、原型链键或非字符串 | 回退该阵营默认外观，不改变阵营/金额/库存 |
| 后续input伪造外观/金钱 | 不作为客户端权威状态采纳 |
| 模型/贴图缺失、路径/结构/散列错误 | 明确紫红线框和诊断，不将其当原版加载成功 |
| 快速换选项、异步旧请求返回或对象已销毁 | 旧结果不挂入场景；资源释放/有界缓存 |
| 对方移动/远距离复活 | 远端模型位置平滑；大距离直接跳到新点，不沿地图飞行 |
| 角色躲墙后 | 普通世界layer 0、开启深度测试/写入，不进入第一人称前景层 |
| 蹲下 | 切源动作与18-unit中心偏移，不压扁人体网格 |
| 死亡 | 播源死亡序列并停末帧；不替代服务端存活/胜负判定 |

角色内部坐标为`(-sourceY,sourceZ,-sourceX)/40`，相对脚底加站立0.9/蹲伏0.45的源hull中心；这一固定朝向基变换不能用第一人称镜像矩阵替代。地图仍是`(X,Z,-Y)/40`，比例未改。
