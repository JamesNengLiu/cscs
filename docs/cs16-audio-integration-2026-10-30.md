# CS1.6 声音集成与验收 — 2026-10-30

## 结论、目标与非目标

本轮在现有网页版 CS 上实现声音事件路由、原始名称 WAV、耳机 HRTF/扬声器立体声、听者旋转、距离衰减和联机预测去重。重点是能通过实际敌方脚步的方向定位，声音不能因敌人未被渲染而消失，也不能因 ACK/重放变成双声。

**不是已经零差异复刻了 GoldSrc。** 社区源码和资源镜像不构成零售版认证；没有实体耳机盲听、原版同步录音 A/B、原版逐资源散列与各房间声学验收。HRTF 是 Web Audio 实现手段，不代表 CS1.6 原版使用同一算法。地图、碰撞、枪械伤害、运动与联网架构不为音效而改比例或规则，不引入 Wasm。

## 空间定位与设置

- 世界位置沿用项目坐标，源地图40单位/世界单位；不会在音频里再对位置重复缩放。
- 听者使用实际相机位置与朝向，声源使用事件世界位置，不根据视野/FOV/人物可见性裁剪。
- 默认耳机 HRTF；扬声器模式为 equalpower 左右声像。后者本来不能依靠滤波提供同样的前后辨位。
- 自己的脚步/动作/枪声为本地反馈，远端脚步/枪声/爆炸空间化；UI、队伍无线电与播报不被错误放在地图原点。
- 菜单有总音量、战斗环境音、语音、启用开关、输出模式与左/右/前/后试听；本机持久化，存储拒绝时说明设置仅当前页有效。
- 前后滤波存在不等于每个人都能盲听正确。请使用双声道耳机，避免系统/耳机再次叠加虚拟环绕；小幅转头可辅助前后判断。
- 当前使用线性衰减；名义裁剪距离1000源单位、衰减参数和 Web Audio 声像属于本轮工程实现，**未通过零售引擎逐距离等响度校准**。

## 材质、节奏、权威与去重

`public/audio-surfaces.js` 从实际 BSP 渲染面和 materials.txt 查材质，校验地图来源 SHA 与碰撞数据一致；不按纹理英文名猜脚步。脚步查表剥离动画/特殊前缀、16字符比较、未知默认 concrete。木材不是虚构的 pl_wood 脚步。

移动声音参考固定 ReGameDLL 的 PM_UpdateStepSound/PM_Jump/PM_CheckFalling：全3D速度换算到源单位，普通速度 >150 才进入运行步声；通常300ms；材质/水/梯子/蹲姿有各自规则。独立声音状态只在正常推进执行，重算移动不重新触发音效。目录/函数支持水与梯子规则不等于当前地图已有完整游泳/爬梯玩法。

`game.mjs` 独立使用 audioRandom，音效变体不消耗弹道 RNG；`event-visibility.mjs` 在服务端过滤私人/队伍事件；`public/world-audio.js` 有界事件/命中去重；`public/game-audio.js` 有声道替换、过时事件丢弃、异步取消和资源预算。

枪声规则的补充参考是 [FWGS/cs16-client a238ef1 的事件目录](https://github.com/FWGS/cs16-client/tree/a238ef131803ed7592c4ba701499027c862889ee/cl_dll/events) 与 [events.h](https://github.com/FWGS/cs16-client/blob/a238ef131803ed7592c4ba701499027c862889ee/cl_dll/include/events.h)。这些是社区重实现，不是零售客户端认证；例如 USP 社区文件的状态命名与播放索引存在不一致，不能把它所有表达式机械当成零售真值。现有明确消音/非消音文件分类仍被保留。

## 资源和预算

- 实际本地准备 **316/316 WAV，0缺失**，另有 materials.txt；全部目录文件保持原始字节，没有用合成音/占位音填补游戏资源。
- 目录316、ACTION292、分组109；本地 manifest 保存逐文件 SHA256/URL/PCM/警告/许可未知信息。原始名称不等于Valve零售版认证。详见[来源和准备](cs16-audio-sources-2026-10-30.md)。
- 最多48活动声源、512缓存条目、64MiB解码缓存、4并行加载、28排队加载、96待播、512事件记录；单个编码WAV2MiB，解码16MiB，加载超时8秒。
- 本机316文件在44.1kHz/48kHz重采样为 Float32 的体积超过32MiB；实测完整预热会触发旧32MiB预算淘汰。因此最终采用有界64MiB，而不是凭压缩WAV体积估算内存。更高设备采样率仍允许LRU淘汰，不保证所有设备同时缓存全目录。
- 音效目录、manifest、参考源码、日志、截图和本地TLS材料不新增进Git；社区可下载不代表有再分发许可。
