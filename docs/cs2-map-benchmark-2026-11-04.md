# CS2 Dust2 独立地图性能验证

本批只做地图渲染与加载的可行性验证。`v1.0.0`（`0dc0b69`）的运行源码、地图、准星、弹道、移动与联机规则保持不变；不重启现有 3001 游戏进程，不加入现有房间。临时静态回环测试页不包含 Game/WebSocket 服务，用完关闭。是否继续迁移由用户根据实测结果决定。

## 数据与布局保真

- 地图来自 Valve 公开分发的 app 730 / depot 2347770，固定 manifest `3690356453703667427`；`de_dust2.vpk` SHA-1 为 `7dc529cd65d843a2b8a98c297e79b9923dd70a5d`，下载后逐文件校验。
- 使用开源 [Source 2 Viewer / ValveResourceFormat 20.1](https://github.com/ValveResourceFormat/ValveResourceFormat) 导出。它是项目隔离目录中的独立命令行转换器，不是网页运行依赖，不安装 Steam、系统 .NET SDK 或新引擎。
- 517 个原始世界模型均进入覆盖核验。过滤不可见工具层和贴花/粒子覆盖层后，保留 **4,535,745** 个三角形；空间分为 **181** 批，未缩放地图比例、未简化保留三角形的形状。遗漏一枚装饰性足球实体，不计为主结构或掩体。
- 保留转换器的米制坐标：Source `(X,Y,Z)` 到样本 `(Y,Z,X)×.0254`。两处实际放置实体校验误差不超过约 `.022mm`，打包位置的 Float32 舍入误差不超过约 `.004mm`。A/B 观察点取真实炸弹触发体边界，出生点取真实实体；不沿用旧地图的估计点位。
- 颜色和光照为简化的不透明顶点色 PBR，无原版材质贴图、烘焙光照、Source 2 遮挡/PVS、阴影或体积烟雾。本次不是原版画质或完整 CS2 客户端性能认证。

生成包压缩几何 **46,332,647 字节**，解压 **147,239,004 字节**。位置使用 Float32，法线使用归一化 Int16，色板使用 Uint8，索引使用 Uint32。浏览器原生 gzip 流解压，无 Wasm。读取阶段分片验证属性范围、索引、分区与顶点总量，每约3ms让出真实任务；属性复用同一个 ArrayBuffer。加载画面内预热所有分区 VBO 和着色器，避免首次进入另一片区域再上传大缓冲。

## 验证方法与判定口径

用已安装的原生 Chrome、实际 WebGL2 和真实临时 HTTP 请求，固定 **1280×800、DPR=1、渲染比例1**，不自动降分辨率、不合成 rAF、不修改显示设置。先测空页回调节奏，再测 1.0 地图的隔离渲染对照和 CS2 样本。

1. 新浏览器上下文测首入，刷新同页测浏览器缓存命中；操作系统页缓存/驱动缓存不保证冷。这是本机回环 HTTP，不含互联网时延和生产 HTTPS 握手成本。
2. T/CT 出生点、A/B 俯视和全景逐一取样；正常视角与全景压力分开报告。全景并非对枪时的典型可见范围。
3. 9 个现有 1.0 动画人物和 p_weapon 提供骨骼/绘制压力，不冒充 9 台实体客户端或 CS2 人物。首次人物加载单独记录，稳态与首次加载不混算。
4. 程序化 48 层烟雾精灵与 128 粒子用于透明/更新压力；透明层关闭深度测试以保证不是被墙挡住的空负载，不等价于 CS2 原版体积烟雾。
5. 自动巡游及前台两分钟压力观察记录 FPS、P99/最长帧、1% Low、CPU 提交、独立异步 GPU 查询，以及几何/纹理计数与内存走势。

预先设定的样本门槛：稳态 60 帧档为平均 ≥58 FPS、P99 ≤22ms；近 120 帧档仅在空页实际回调 ≥110Hz 时判定，要求平均 ≥115 FPS、P99 ≤10ms。首次人物加载与全景压力另报，不折进稳态门槛掩盖。首入目标 ≤5s、压缩地图资源目标 ≤150MiB。这些是本批验证预算，不是跨设备保证，也不授权自动继续迁移。

JS heap、解压缓冲区、估算的地图顶点/索引 GPU 字节数和浏览器各进程 RSS 合计分开列。RSS 含共享页重复计算，不是独占物理内存；GPU 属性字节数不等于完整显存，未计驱动、帧缓冲等。两分钟计数稳定也不能证明长期零泄漏。

## 复测和使用

原始及派生资源、工具二进制、截图和收据继续隔离在 `.local/`、`public/assets/`、`artifacts/`，不纳入 Git。准备程序不自动下载资源或软件；需要已经取得的固定地图包与本地转换器：

```sh
python3 tools/prepare-cs2-benchmark.py \
  --map .local/cs2/source/game/csgo/maps/de_dust2.vpk \
  --viewer .local/cs2/tools/source2viewer/Source2Viewer-CLI

node tools/benchmark-cs2-map.mjs
node tools/benchmark-cs2-map.mjs --headed

CS2_BENCH_WIDTH=1920 CS2_BENCH_HEIGHT=1080 node tools/benchmark-cs2-map.mjs --headed
```

准备程序只将临时 VPK 搜索路径暴露给转换器，不加载整个 CS2 共享包目录。转换器可能记录异常但退出码为零，因此还检查异常日志、导出文件、主结构覆盖和实体坐标，不能把残缺导出当成功。临时解包和 glTF 中间文件完成后自动删除。

生成资源后，独立页面为 `/cs2-map-benchmark.html`，不加载游戏客户端、不发送加入房间消息。支持自由观察、视角按钮、压力开关和导出诊断。自由相机不是玩家移动，测试不覆盖新碰撞求解、射击、网络或原版材质管线。正式游戏入口仍为 `/`。

原始收据：`artifacts/cs2-map-benchmark-headless.json`、`artifacts/cs2-map-benchmark-headed.json` 及对应截图。CPU、GPU、帧间隔、首次加载和内存分别查看；真实高刷的测量结果以该次空页节奏为准，不以配置项或 GPU 余量推断。

## 最终实测结果

设备为 Apple M1 Pro / 32GiB RAM，原生 Chrome `156.0.8078.80`，ANGLE Metal。前台空页实际回调约 **75.19Hz**，并非120/144Hz验收。下表为最新分片加载版本的 **1920×1080、固定DPR=1**；1.0 列同样是隔离地图渲染对照，不是整个游戏的所有CPU开销。

| 指标 | 1.0 地图对照 | CS2 简化材质样本 |
| --- | ---: | ---: |
| 浏览器缓存冷的首入 | 219ms | 975ms |
| 浏览器缓存命中后首入 | 120ms | 909ms |
| 正常观察 / 压力 / 巡游平均FPS | 约75 | 75.00–75.03 |
| 正常视角及压力最大P99 | 约15.3ms | 15.3ms |
| 最新CS2样本最长观察帧 | — | 15.5ms |
| 正常视角/压力中 >25ms / >50ms 帧 | 0 / 0 | 0 / 0 |
| JS heap，压力结束并GC后 | 28.1MiB | 165.8MiB |
| 浏览器进程RSS合计，压力结束 | 1.16GiB | 1.76GiB |

RSS 包含共享页重复统计，不能当作地图独占内存或GPU显存。地图解压缓冲约 **140.4MiB**，与JS内存统计存在包含关系，不应简单相加；地图GPU顶点/索引字节数另估算约 **140.4MiB**，不包含其他GPU分配或驱动开销。

最新两分钟巡游包含9个动画人物及程序化透明层/粒子：几何数 **201**、纹理数 **22** 始终不变；10秒/120秒采样的JS used分别约174.49/175.26MB，RSS合计约1.735/1.756GiB，GC后JS heap回到约165.8MiB。采样期间RSS变化不是零，不能据短测宣称长期无泄漏。正常/压力各阶段GPU P95最高约 **6.19ms**，CPU P99最高约 **2.1ms**；不是把CPU提交时间当GPU时间。

初次人物加载单独记录，最新CS2场景最大帧约 **15.3ms**。最初同步遍历整份几何曾产生 **181–189ms** 加载长任务；改为有界分片验证后，最新冷加载未观察到 ≥50ms 主线程长任务。传输+解压约313ms，校验/建立分区约248ms，全图预热约319ms，其余是模块/调度开销。分片前收据另存为 `*-before-loading-yield.json`，没有覆盖失败证据。

1280×800 的初轮前台对照也约75FPS，headless原生回调约60Hz，两者均不用于宣称120/144Hz通过。最新全高清收据为 `artifacts/cs2-map-benchmark-headed-1920x1080.json`，记录本次渲染源码哈希与固定地图身份；该文件及截图保持忽略。

本批完整自动化 **1818项通过、零失败/跳过**；原1810项保留，新增8项覆盖VPK资源完整性、错误/危险路径、CRC与引用指针，以及几何缓冲/协作校验。与 `v1.0.0` 比较，所有原有受跟踪文件保持不变，原3001游戏PID保持不变。验证源码新增在独立页面与工具中，没有改准星、弹道或移动。

结论：**该简化材质、固定DPR=1样本在本机通过60帧可行性门槛，并跑满本次约75Hz回调。** 内存成本较1.0明显增加；原版材质/光照、新碰撞链路、实际多人同步、低配设备、120/144Hz仍未验证。通过本批渲染验证不代表完整CS2迁移达标，也不自动开始其他玩法改动。

## 资源清理

已停止原先的大批共享资源下载。按固定官方清单核验后，删除69个中断/校验不完整分包；随后证明零共享包导出的几何二进制与原样本逐字节一致，删除6个完整但本批不再需要的共享包、下载器、工具ZIP重复包、重复glTF/物理导出和临时解包目录。

按已删文件的分配块统计，累计清理约 **1,926,705,152字节（1.79GiB）**，不是声称实际下载过或释放了7.9GB。保留的项目隔离数据约 **415.8MB**，生成的浏览器样本约 **46.7MB**，合计约 **441MiB**；主要是已校验原图和可复现转换所需的独立转换器。没有清除1.0地图、人物、枪械、音频、证书或依赖。准备程序完成后会自动清理自己的临时中间文件。
