# CS2 Dust2 贴图与光照独立验证

本轮仅扩展独立地图渲染页。`v1.0.0` 的原有受跟踪文件、原地图、准星、弹道、移动、联机代码和 3001 服务状态保持不变。贴图版入口为 `/cs2-map-benchmark.html?dataset=textured`；旧简化版和 1.0 地图渲染对照仍可选择。静态预览不创建游戏房间，不代表可以在新地图上对战。

## 数据与画面范围

- 原固定 Steam manifest 已返回 401；本轮通过匿名官方 depot 2347770 的当前 manifest `6679288287140932208` 获取索引及必要资源。原始完整清单缓存 SHA-256 为 `c7f057fde36c7a47e79007bf5a7289b58925f6da7fc17323fcef29f6e453fb54`。
- 新清单中的 Dust2 VPK 与上一轮逐字节身份相同：SHA-1 `7dc529cd65d843a2b8a98c297e79b9923dd70a5d`。布局、尺寸、位置和原始三角形没有变形或简化。原简化样本仍保留独立资源，方便对照。
- 使用项目内 [Source 2 Viewer 20.1](https://github.com/ValveResourceFormat/ValveResourceFormat) 读取模型、材质参数及输入语义。没有安装 Steam、系统 .NET SDK、Blender、新引擎或浏览器 Wasm 运行时。
- 下载只选取 VPK 索引里实际引用资源覆盖的数据块；原始 chunk ID、偏移及校验值不变，下载后再按原始 VPK 索引 CRC 逐项核对。临时稀疏 VPK **不是完整共享包**，不能按其逻辑尺寸声称已下载或校验了整个包。局部下载计划和官方完整清单分目录保存。
- 加入原始底色、法线/粗糙度、金属度、着色遮罩、双层混合、透明裁切、真实贴花与标识；保留可用的原始 mip 链，常规贴图最高 1024。采用 WebGL 原生 BC1/BC5/BC6H/BC7 等压缩格式，不把所有纹理展开成 RGBA，也不使用 Wasm 解码。
- 接入原始 HDR 间接光图、方向光照图、烘焙太阳阴影遮罩及 HDR 天空立方图。间接光/阴影最大 4096，太阳方向来自地图实体（50°/43°）；材质与 BRDF 使用 Three.js 近似。
- 箱体的 `F_FORCE_UV2` 需要第二套贴图 UV；光照 UV 则依据转换器对编译光照通道施加的 `1.14283965` atlas 比例，与无材质导出的同一几何逐项比较确定。没有把所有 `TEXCOORD_1` 都当光照。
- 植被 `COLOR_0` 的风动/AO 数据不作烘焙照明。没有有效导出光照 UV 的道具采用披露的环境光近似，避免把紫红风动数据错误地加成发光颜色。

保留约 454 万个三角形，真实贴花比简化版略多；模型和包围盒覆盖、Float32 位置误差与上轮基准核对。**这仍不是完整 CS2 画质**：未复现 Source 2 的 LPV/局部反射探针、PVS/遮挡、3D 天空背景、体积雾、原版后处理、植被风动、动态世界阴影，以及所有材质特性。转换器本身[不在 glTF 中导出烘焙光照](https://s2v.app/ValveResourceFormat/guides/format-support)，本轮另外提取并接入相应光照纹理。

此固定档位要求浏览器支持对应原生纹理压缩扩展；不支持时明确报错，不以纯色或缺失纹理的帧率代替成功结果。低配、其他 GPU、120/144Hz 及真正多人完整游戏性能尚需另外验证。

## 方法与门槛

原生 Chrome、1920×1080、DPR=1、固定渲染比例 1，依次跑 1.0 地图隔离渲染、CS2 简化样本、贴图光照版。测试使用临时本机 HTTP 静态夹具并自动关闭，不启动游戏服务器。

分别测浏览器缓存冷的首入、缓存命中后重新建立场景、T/CT/A/B/全图视角、9 个现有 1.0 动画人物与程序化透明/粒子压力、首次人物加载、两分钟巡游。全图压力单独列出。CPU 提交、异步 GPU 查询、rAF 帧间隔分别报告。这里的本机回环加载不包含真实局域网/互联网带宽、HTTPS 握手，也不保证 OS/驱动缓存冷。

沿用上一轮门槛：稳态 60 帧档平均 ≥58 FPS、P99≤22ms；首入≤5s、压缩请求资源≤150MiB。120 档仅在空页实际回调≥110Hz才判定。没有为了让新样本通过而放宽预算。几何/纹理计数、JS heap、CPU/GPU 缓冲估算和浏览器各进程 RSS 合计分开报告；RSS 含共享页重复统计，不等于地图独占内存或完整显存。

## 复现

素材、下载器、转换器二进制、截图及原始收据保持在被忽略的目录中，不提交。下载器只需要准备资源时使用；不加入网页运行依赖。离线准备使用已经 CRC 核验的资源目录：

```sh
python3 tools/prepare-cs2-textured.py \
  --resources .local/cs2/textured/extracted \
  --map .local/cs2/source/game/csgo/maps/de_dust2.vpk \
  --viewer .local/cs2/tools/source2viewer/Source2Viewer-CLI

CS2_BENCH_WIDTH=1920 CS2_BENCH_HEIGHT=1080 \
  node tools/benchmark-cs2-map.mjs --headed --textured
```

材质索引导出阶段仅挂载真实 VMAT；转换器生成的占位 PNG 不进入浏览器资源，随后删除。运行时纹理全部来自 CRC 核验过的原始 VTEX 数据。二次无材质 UV 参考导出在临时目录完成，临时目录自动清理。

## 本轮结果

设备为 Apple M1 Pro / 32GiB，Chrome 156.0.8078.80 / ANGLE Metal。空页实际回调约 **75.19Hz**；本轮不能验收 120/144Hz。分辨率固定为 1920×1080、DPR=1。

完成测量后，在用户日常 Chrome 新标签页打开贴图版并确认加载、显示正常：该次界面显示加载约7.9秒、T点约51.5FPS。其视口和日常浏览器环境与固定夹具不同，此观察单独记录，不替换下表的标准对照值。

| 指标 | 1.0 地图渲染对照 | CS2 简化材质 | CS2 贴图与光照 |
| --- | ---: | ---: | ---: |
| 缓存冷的首入，本机 HTTP | 229ms | 978ms | **5863ms** |
| 缓存命中后重建场景 | 118ms | 950ms | **5539ms** |
| T 视角平均 FPS | — | 75 | **49.5** |
| CT / A / B 视角平均 FPS | — | 75 | **约75** |
| 全图压力平均 FPS | 75 | 75 | **40.5** |
| 程序化人物/透明层压力，CT 视角 | 75 | 75 | 75 |
| 压力巡游平均 FPS | 75 | 75 | **64.2** |
| 压力后 GC 的 JS heap | 28.2MiB | 165.5MiB | **668.6MiB** |
| 压力结束浏览器进程 RSS 合计 | 1.17GiB | 1.71GiB | **3.85GiB** |

RSS 含共享页重复统计，并非地图独占内存。未采样首入瞬时内存峰值。解压几何约 **283.0MiB**、纹理数据约 **342.6MiB**，与 JS heap 存在包含关系，不能额外叠加当总占用。地图 GPU 顶点/索引约 283.0MiB，纹理 GPU 存储估算约342.4MiB，未包含驱动、PMREM、帧缓冲、人物等全部 GPU 成本。

本档位实际请求的压缩几何与纹理共约 **323.0MiB**，不含少量模块/JSON开销；其中几何约77.8MiB。首入中传输+原生解压约2033ms，分片校验/建图约626ms，纹理/材质/VBO预热约3087ms。仍观察到3个加载期主线程长任务，最长89ms。已有缓存仍需重建GPU资源，不能把缓存命中当作立即进入。

这不是局域网带宽测试。仅以323MiB数据计算，100Mbps链路的理想传输下限约27秒，尚未计协议、竞争和加载处理，实际不保证达到；不能将本机5.9秒推广为其他玩家的首次加载时间。

T 点 P99 约 **27.5ms**，2500ms采样中64帧超过25ms；该视角约1439次绘制、332万三角形、GPU P95 13.29ms、CPU P99 5.5ms。CT 为约337次绘制、89万三角形、GPU P95 7.88ms、CPU P99 2.8ms。这些数据指向大量可见批次/未做遮挡剔除的绘制成本，尚未通过独立的剔除 A/B 将贡献精确分解。CPU/GPU异步执行，不能把两项百分位直接相加当帧时间。

两分钟压力巡游平均约 **65.6FPS**，P99约27.6ms，最长40.1ms；1103帧超过25ms，未见超过50ms帧。首次人物与特效压力加载另外出现 **67.2ms** 长帧，不能隐去。持续测试几何2244、纹理719保持不变；10秒/120秒JS used约707.96/706.83MB，RSS合计约3.830/3.848GiB。此短测未见计数持续增长，但不等于长期泄漏或其他设备已验收。

**结论：画面接入与本机渲染验证已完成，本档位未通过原定60帧稳定性、5秒首入、150MiB资源预算；不能据此替换1.0或宣布完整迁移达标。** 下一步优先验证遮挡剔除/合批，减少T点绘制压力；随后压缩首入常驻纹理和分级加载，并补齐首次人物/特效预热，再复测相同门槛。进一步提高原版贴图尺寸/增加LPV、反射与雾效应在这些预算收敛之后单独验证。

完整汇总为 `artifacts/cs2-map-textures-lighting-2026-11-05.json`。最终贴图版原始测量为 `artifacts/cs2-map-benchmark-headed-1920x1080-textured.json`，状态completed、错误为空、夹具已关闭；失败接入记录保留。1.0和简化版对照取自同轮已完成的控制阶段（`*-before-tint-fix.json`），不使用其失败的贴图阶段；两次之间只修改了独立贴图模块的着色遮罩类型，共用页面与控制渲染源码哈希已核对相同。原始测量的旧顶层scope模板仍沿用简化版文字，实际模式按dataset与manifest.quality区分；汇总已使用准确描述，不改任何原始测量值。原始收据、截图与汇总保持Git忽略。

本轮 `npm test` **1824项通过，零失败/跳过**；新增6项覆盖纹理mip/立方图字节与截断、资源CRC回读、子集块边界/错误路径、贴图/光照UV区分、风动颜色语义、几何属性损坏。几何gzip及706张原生纹理gzip的长度和SHA-256逐一通过；1005个保留的原始资源按官方索引CRC复核。所有原有受跟踪文件仍与 `v1.0.0` 一致，未重启3001或改变既有游戏规则。自动化、渲染压力与真实多人/输入手感验证分别看待。
