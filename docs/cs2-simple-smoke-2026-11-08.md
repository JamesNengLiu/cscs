# CS2 烟雾性能优先简化

用户选择优先保证性能，将烟雾改为一团平滑雾气。本轮在 `codex/cs2` 修改呈现层；没有更改投掷轨迹、反弹、跳投、起烟时刻、伤害、弹道、后坐力、人物移动或经典 1.0 文件。未增加依赖、贴图或工具安装，未提交、推送或重启现有服务。

## 渲染取舍

此前的烟雾并非粒子系统，而是深度约束的逐像素体积采样：最近四团各做八次密度计算，含三角噪声、子弹通道和爆炸扰动；另外最多 28 团使用保守解析遮挡。

现在默认采用 `simple-depth-fog`：

- 不做体积密度逐步采样、不生成粒子、不使用动态噪声。
- 每团雾只计算与视线的解析交段，并按场景深度截断；累加光学厚度，最后一次指数衰减，浓雾直接饱和遮挡。
- 保留柔边，核心 80% 半径不减密度；外缘使用解析径向权重，避免呈现成边缘生硬的灰色椭圆。没有为柔边增加采样、纹理或绘制通道。
- 保留原范围、高度、膨胀与消散时钟，最多 32 团。无可见烟雾时没有额外绘制；有烟时仍是一次世界渲染和一次全屏合成。
- 保留深度纹理、目标复用、动态分辨率视口对齐及全部首次使用预热；进烟不会出现透明空心壳，墙前像素不会被墙后烟雾覆盖。
- 去掉子弹打孔和 HE 吹散的视觉细节。服务器原有字段继续保留，保证旧数据与事件链兼容；简化呈现不再读取或复制这些扰动元数据，不改变子弹命中或伤害。

这仍有基础场景颜色/深度目标和合成的 GPU 成本，不等于零开销。没有降低地图分辨率、材质质量或人物渲染数量来获得性能数字。

## 核验

完整自动化测试 **2,494 项通过，零失败、零跳过**。新增六项呈现行为测试，已有视口、目标复用、异步预热恢复、枪械与移动回归继续通过。

实际浏览器像素检查覆盖：不透墙、烟内遮挡、第五团成为唯一遮挡物、解析柔边、不再显示子弹/HE 扰动以及 WebGL 错误检查。另有八种真实深度/动态分辨率组合通过，包含 1/1.25 backbuffer 容量和 1/.85/.75/.7 活动比例。小像素夹具的同步 readPixels/finish 结果没有被拿来当作 FPS。

## 完整地图 GPU 对照

固定旧版为提交 `53b2a7bf1d293f91e6a19ee304994dda1c43e9f4`，只通过测试路由切换烟雾模块，其它客户端与权威保持一致。使用独立 Chrome、Apple M1 Pro Metal、1920×1080、DPR 1、sharp 画质，在匪家往 A 方向的 `T-ramp-middle` 站点对照，烟团中心方向 7m 视线无遮挡。新旧相机及渲染负载保持一致，不把 teleport 夹具的 HUD 状态当作自然移动测试。

五个场景各进行旧→新→旧，每窗口五秒，共 15 个窗口、4,503 次实际应用帧回调。

| 场景 | 两次旧版整帧 GPU 均值的平均 | 新版整帧 GPU 均值 | 变化 |
| --- | ---: | ---: | ---: |
| 无烟 | 4.636ms | 4.628ms | -0.2% |
| 单团 | 4.602ms | 4.342ms | -5.7% |
| 四团重叠 | 6.413ms | 4.772ms | -25.6% |
| 烟内 | 7.367ms | 4.388ms | -40.4% |
| 32 团重叠 | 8.362ms | 8.541ms | +2.1%，没有明确稳定收益 |

数值包含地图和前景武器，不是独立烟雾 pass 的耗时，也不表示帧率提高了相同百分比。无烟在三个阶段均为零额外合成；所有场景约 60 次帧回调/秒，无超过 50ms 的间隔或 Long Task，首次烟雾没有新增 shader program，新旧各场景的 draw calls 和 triangles 相同。

32 团压力档保留了波动：旧版两次 GPU P99 为 14.49/10.43ms，新版为 12.16ms。因此没有宣称该极限场景所有指标都下降，也没有把本机自动化当作实体多机、75/120Hz 呈现或实物鼠标延迟认证。

## 复现与记录

先按 `ASSETS.md` 准备本机资源和依赖；浏览器脚本默认使用 macOS Chrome。以下命令在仓库根执行，各浏览器测试仅创建并清理自己的随机回环服务与 Chrome，不连接持久 3001 对局。

```sh
npm test
node tests/cs2-smoke-browser.mjs
node tests/cs2-smoke-viewport-browser.mjs
node tests/cs2-simple-smoke-performance-browser.mjs --prepare
node tests/cs2-simple-smoke-performance-browser.mjs --run
```

本地收据在 `.local/cs2/simple-smoke-2026-11-08/`，包含完整测试日志、像素结果、A/B/A 原始样本、摘要、源码哈希及截图。首版硬边雾的结果也单独保留为 `*-before-soft-rim.*`，没有覆盖为柔边版本的成绩。资源和本地收据继续遵循忽略规则，不随代码提交。

本轮仅前端烟雾模块改变，已有服务可继续运行；试玩需要重新加载网页，联机各方均应刷新到相同呈现版本。
