# CS2 匪家斜坡与车辆落地镜头衔接

本轮仅调整 CS2 验证版显示。默认位置镜头 A 增加很短的地面高度响应；落地倾斜幅度减小、起止变柔和。弹道、人物碰撞、移动速度、跳跃冲量、疲劳、网络协议及 1.0 源码保持不动。

## 显示实现与边界

`cs2-terrain-camera.js` 使用 15ms 单调指数响应，额外高度偏移硬上限 15mm。只处理原位置时钟已采样的脚底 Y；眼高、原台阶 offset、网络 correction 仍沿原算式应用。采用已采样的显示时刻差，不重新引入 RAF 回调相位噪声。停止后偏移归零。

空中、落地后的八个固定步、蹲起变化后的八个固定步及原台阶缓动期间不叠加该响应。平地零偏移时不增加安全射线。位置镜头 B 的 responsive 预览保留原 XYZ 行为。

原有安全相机点先照常求出；新偏移另做同 X/Z 的短竖向检查及人物眼位到候选点的检查。任何不安全结果都退回原安全 Y，并清除新响应状态；不拿新命中点覆盖 X/Z。小幅网络 rebase 同步平移响应；grounded/眼高变化、传送、模式切换、暂停和达到客户端 50ms 时间上限时清除该响应。15mm 仍是显示视差，不宣称相机与物理射击起点永远同位。

落地 Y 试算中，较强的一阶滤波会放大部分车跳落地的速度转折。因此本轮保留原空中及落地高度收尾，不添加向地下的 dip 或额外反弹。车辆减晃通过 `cs2-view-feedback.js` 完成：常见车跳默认倾斜峰值约 0.3°，全强度上限 0.6°，45ms 达峰、160ms 平滑归零；保留旧阈值、220ms 防重复门控及用户开关/强度。只输出 roll，不添加 pitch、yaw 或 Y punch；枪模 bob 原函数直接复用。共享 `view-feedback.js` 未修改。

默认入口启用上述 CS2 显示。临时对照 `?camera=baseline&terrainCamera=legacy` 会恢复本轮修改前的 CS2 位置显示与落地 roll；它不会回退地图、移动或枪械规则。既有 `present=headroom` 画质对照独立保留。

## 定向路线

不再以 T0 面向 B 的路线代替测试：

- 匪家往 A 门的斜坡段：Source `(-550,-840)` 向 Source +X，运行时起点 X/Z 约 `(-21.336,-13.97)`、yaw=π。另用实际 PHYS 回放四条平行上下坡线，每段约 21m；这不是完整出生点到 A 门全程认证。
- A 大靠警家方向车辆：Source `(1700,2050)`，实际车顶约 `(52.07,1.5427668,43.18)`，支持面 `world:0:hulls:1819`、材质 `metalvehicle`。面向 CT，先助跑再单次跳下；浏览器记录实际助跑 16 个预测步，不靠注入输入凑结果。

## 验证结果

- 全量 `npm test`：**2228 项通过、0 失败、0 跳过**。新增测试覆盖 60/75/120/144Hz 的有界响应、停止归零、平地/普通跳/蹲起不叠加延迟、网络 rebase、长帧、遮挡回退及 responsive 模式不变。高刷部分为 CPU 模拟，不是实体高刷显示器认证。
- 18 段真实 PHYS pose 的 75Hz 离线回放：八条坡线的离散竖向加速度峰值降低约 36%–41%，最大偏移 14.278mm；空中与受保护落地收尾没有改变，最终残差为零。legacy selector 与修改前保存的相机源码逐帧 XYZ 相同。收据 `.local/cs2/terrain-audit/camera-fix-verification.json`。
- 后台功能检查四组通过。旧/新车跳均 16 步助跑，未出现位置 correction；记录的倾斜峰值约 1.365°→0.298°。这是 Chrome 157、Metal、1920×913 的后台约 60Hz 功能检查，不能当作前台帧率结果。
- 手动解锁后，前台旧/新 × 两条路线四组通过，实际原生最大化 1920×814、DPR1、外接屏回调约 75Hz，锁鼠/焦点/可见性检查通过。坡面 CPU 均值 4.283→4.317ms，P99 5.5→5.4ms；车辆 CPU 均值 5.552→5.668ms，P99 8.1→8.6ms。车辆倾斜峰值 **1.466°→0.297°**，新安全检查未拒绝这些路径。
- 前台个别帧存在预测校正，旧车路线最大约 2.3cm，新坡路线最大约 5.5cm；没有把这些波形一概当作相机平滑误差。该短样本不认证完整地图、弱网或长期稳定性。坡道呈现关联覆盖完整，车路线有多 RAF 歧义，未将其部分呈现关联当成完整显示帧率证明。之前的浏览器固定呈现等待也不由本轮宣称解决。
- 后台武器/移动保护检查完成：原生刀模型、AUG/SG 开镜、AWP 2/1 与连续 Q/Q、精确鼠标计数、跳跃落地、蹲下站起及原有画质 A/B 切换，WebGL 错误为 0。

前台早期两次尝试分别因窗口状态约束与 Mac 锁屏无法捕获鼠标失败，收据保留且未算通过；用户解锁后使用相同尺寸的新旧窗口重新完成验证。所有自有窗口、临时 profile 和临时测试服务已关闭。
