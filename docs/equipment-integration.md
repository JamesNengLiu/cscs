# v0.4 武器、购买与经济接入验收

日期：2026-10-27。开发分支：`feat/cs16-arsenal`。这是可运行的开发实现和本机验证记录，**不是完整CS1.6一比一认证**。3001稳定v0.3未被替换；本轮浏览器临时服务已关闭。

后续规则更新（2026-10-28）：买枪附赠满弹匣和满备弹，新回合携带枪械自动补满；商店与服务端取消弹药销售。下文付费补给、存活保留剩余弹药及对应金额收据属于历史版本，当前规则见README；原口径共享和备弹上限继续沿用。

## 目标与范围

将原先免费切换原型枪的方式替换为服务端权威的CS1.6武器目录、购买、库存、护甲、投掷和回合经济。用户唯一明确金额覆盖值是首次加入 `$10,000`；不能每回合重新发放，也不能将此覆盖值称为原版默认。

已接入：

- 24把枪的目录、价格、阵营、弹匣、口径、备弹上限、射速和装填参数；每把枪均经真实Game购买/切换/开火集成测试。
- 默认阵营手枪与刀；主副武器槽，刀主攻击/刺击，枪械连发、消音和开镜。
- HE最多1、闪光最多2、烟雾最多1；投掷物有服务端轨迹、计时与作用，客户端显示闪光/烟雾。物理/遮挡和视觉并非完整原版实现。
- Kevlar、头盔、拆弹器、夜视仪与CT盾牌。满甲补头盔350、已有头盔补甲650，共用服务端/UI报价；重复和非法购买不扣款。
- 真实BSP己方购买触发区、90秒购买窗、存活与阵营限制；购买请求只有商品ID，不能用客户端价格/金额改变结果。
- 共享口径备弹、付费补给、霰弹枪逐发装填、切枪不补弹、武器丢弃与拾取；死亡按最佳枪/盾牌掉落，CT拆弹器可被回收。世界掉落展示与备弹包装仍有简化，不能据此宣称完整库存等效。
- 存活保留装备/弹药；死亡在下回合恢复阵营默认装备而不重置账户。
- 回合奖励、击杀奖励、余额上限和连败共享状态；T超时存活无回合补助。原版路径与新版本差异及固定源码提交见 [cs16-sources.md](cs16-sources.md)。
- 首次金额10000、上限16000、击杀300；胜负奖金在下轮入账，重复结束不会重复发钱。根据所核对参考分支，不添加CS:GO式个人安拆奖金或武器特定击杀奖金。
- 定向事件与个性化快照；对手快照不含余额、库存、备弹池和闪光私有状态。

## 忠实度未完成项 / 本轮非目标

1. 全套人物模型仍是原型网格，第三人称枪械、世界掉落模型和部分盾牌组合模型未完整移植；第一人称源模型导入不能代替人物需求。
2. 命中盒按简化身体分区，不是原始动画骨骼hitbox；未实现完整材质穿透、弹丸及水体语义。
3. 各枪散布、后坐力、恢复、移动精度、刀碰撞、动作切换锁定等含原型近似；目录参数与基本分支对照不等于原版枪感。
4. 原始动画轨道真实存在，但选择及播放仍由启发式驱动，不是完整原版武器状态机；消音器外观、逐发装填、左右枪、投掷、刀刺/挥、盾牌等尚未逐项对齐。射击音效、弹壳与原始事件未完整接入。
5. HE/闪光/烟雾碰撞、环境/玩家遮挡、烟雾持续与视觉、夜视显示有简化，详见 [grenades-fidelity.md](grenades-fidelity.md)。
6. C4爆炸完整范围伤害与场景破坏、所有原引擎物理/光照/gamma细节未移植；本轮不以重画地图或删除碰撞掩盖差异。
7. 账户身份使用当前连接，不是Steam身份与跨重连持久化；重新加入/服务重启不能宣称保留原账户。
8. 实体双电脑Wi-Fi、10人压力与目标硬件性能未验收，自动化通过不能替代实玩。
9. 来源镜像一致不等于官方零售版本认证；原版和派生素材许可未确认，不上传公开仓库。
