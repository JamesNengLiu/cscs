# 游戏菜单与鼠标灵敏度

日期：2026-10-28。最初基于 `feat/smooth-rendering` 实现，现已纳入 `main`，未改服务端规则。本文保留当时验收快照；后续直接在 `main` 迭代，发布提交以远端 `main` 为准。

## 使用

- 大厅点击“游戏菜单 · 鼠标 / 画质设置”，无需加入房间。
- 对局中按 Esc 打开菜单并释放鼠标；点击“继续游戏”重新捕获鼠标。
- 鼠标灵敏度支持滑条和精确数值，范围 **0.10×–5.00×**，步长 **0.05×**，默认 **1.00×** 与旧版相同。
- 新增独立的“狙击枪开镜灵敏度”，范围与步长相同；开镜时在普通灵敏度上乘此倍率，默认1.00×保持原手感，适用于AWP、Scout、G3SG1和SG550的各开镜档位。未开镜和其他枪械使用普通灵敏度。
- 设置即时生效，同时影响水平和垂直转向；“恢复默认灵敏度”同时还原两项鼠标设置，不重置画质。
- 本机浏览器 `localStorage['lan-strike-mouse-sensitivity']` 与 `localStorage['lan-strike-scoped-sensitivity']` 分别保存倍率字符串；同一浏览器/同一来源地址刷新后保留，不跨地址、浏览器、设备同步。浏览器禁用存储时仍可本次使用，并明确提示刷新将丢失。

## 输入与边界

原始基准为 `0.002 rad / mouse movement pixel`，新公式：

```
yaw   -= movementX × 0.002 × sensitivity
pitch  = clamp(pitch - movementY × 0.002 × sensitivity, -1.45, 1.45)
```

狙击枪开镜时，上述双轴转向增量再乘 `scopedSensitivity`；退出开镜、换到其他武器或狙击枪开火后临时退镜期间使用普通倍率。

该倍率不是原版 CS 控制台 sensitivity 参数或物理 DPI/eDPI 认证。俯仰上限、后坐力、服务端伤害与散布规则不变。

数值失效/空白时保留上一次有效值，提交时将有限越界值钳制、按步长归一；损坏存储回到默认。输入中的短暂不完整数字不覆盖当前有效灵敏度，失焦后恢复规范格式。

打开菜单立即清空按键、开火和待重放输入，继续发送中性心跳。菜单期间忽略游戏转向/移动/装备/换弹/购买快捷键，但服务器时间继续，不是全局暂停、无敌或掉线。恢复鼠标捕获只能由用户点击触发，不在关闭菜单或按 Esc 后强行自动捕获。

菜单具备 dialog/aria 标签和焦点循环，背景大厅/HUD/预览设置 inert。购买菜单与游戏菜单互斥，购买菜单关闭后回到游戏菜单。未加入时主要按钮是“返回大厅”，连接断开时是“刷新并重新连接”。桌面和390px窄屏均检查实图，无横向溢出。

## 验证

- `node tests/mouse-settings-browser.mjs` 可在缺少地图素材时单独检查真实设置HTML、双组控件、刷新持久化、恢复默认、存储异常和窄屏布局；它不代表实际联网开镜验证。
- `npm test` 自动发现 `tests/mouse-settings.test.mjs`：默认兼容、倍率、范围、步长、非法值、存储/恢复、只重置鼠标、拒绝/配额异常。
- `npm run test:menu` 使用临时本机随机端口、真实 Chrome/WebGL 和 WebSocket 对手，检查九组行为：大厅入口与默认、滑条/数字边界、真实刷新持久化、恢复默认、焦点约束、真实鼠标捕获后的双轴倍率、Esc 清输入与服务器继续运行、购买菜单互斥、禁用存储。
- 受控的 `movementX/Y` 事件用于核对实际客户端转向增量，不等于测试物理鼠标 DPI/系统加速度。真实用户点击获取 pointer lock 和真实键盘/鼠标开火同时验证。
- 既有双隔离浏览器对战、购买菜单、下坡浏览器、十连接单渲染器回归通过。测试服务器结束后确认端口关闭；现有3001房间未重启，已打开窗口刷新即可加载。

关键文件：`public/mouse-settings.js`、`public/client.js`、`public/index.html`、`public/tuning.css`。本地收据：`artifacts/game-menu-unit.tap`、`game-menu-report.json` 及桌面/窄屏实图。

## 2026-10-29：投掷反馈与本机操作设置

上一轮手感改动先提交为 `549223e`，本节记录后续迭代。当前规则优先于上文历史灵敏度说明：

- 鼠标基础转向系数由 `0.002` 调整为 `0.001 rad/pixel`。数值 1.00 时双轴转向为此前一半，已保存的倍率保持原值；开镜仍在此基础上乘武器 FOV 比例和开镜倍率。
- 菜单新增“持枪与操作 → 持枪方向”，默认右手，可即时选择左手并保存于 `lan-strike-weapon-hand`。只镜像第一人称武器及其原点，不镜像世界、HUD、准星或开镜，也不改变服务端射线。
- 保留 Space 跳跃、C 蹲下以及数字键/Q 切枪；新增滚轮向下跳跃、左右 Ctrl 蹲下。滚轮向上保留上一件装备切换。轮跳以相邻两个模拟 tick 的按下/释放指令进入原有输入队列，满队列时整对拒绝，避免卡住跳跃。菜单和购买界面不产生这些游戏指令，Ctrl 蹲下时按 R 仍为换弹。
- 三种投掷物的显示比例为原先 2 倍，并对相邻服务端快照的位置插值；不改变投掷速度、碰撞、保险准备或引信。停稳立即使用权威位置，不外推未收到的飞行轨迹。
- HE 消费服务端 `explosion` 事件，在实际爆炸点显示短暂火光、烟尘及火星，并立刻移除该 ID 的飞行模型。使用独立原创程序纹理，最多 16 组爆炸、3 个复用绘制批次；约 0.7 秒火光 / 2 秒总视觉寿命，回合切换和释放时清理。闪光和烟雾继续使用其既有玩法，不附加 HE 火球。

验证：591 项自动化测试通过。`tests/utility-settings-browser.mjs` 的 8 项真实客户端/离线 Game 场景通过，覆盖爆炸 WebGL 渲染、左右手/持久化、半速灵敏度、滚轮指令确认、Ctrl 与菜单保护；设置面板桌面/窄屏/禁用存储 3 组、投掷物贴图/资源复用 2 组也通过。浏览器没有页面或着色器错误，没有外部素材请求；截图及收据只保存在忽略的 `artifacts/`，不代表实体双机或目标硬件帧率验收。

这一轮为客户端展示与输入改动，无需重启服务器；已打开的游戏页面刷新后加载。没有推送远端，也未把新一轮改动混入上一轮基线提交。
